# 4주차 오픈 미션 - 경주마

오픈 미션은 자유주제입니다.
저는 경주 시스템과 사용자를 관리하는 대규모 시스템 구현 문제를 만들었습니다.
언어는 자바스크립트를 사용하여 구현하였습니다.

## 구현할 기록 목록

1. [선수와 말 입력] : 선수와 말의 정보를 사전에 입력아 저장한다.

2. [출석 정보 확인] : 저장된 정보에 있는 선수와 말의 이름을 입력 받아 출석을 확인한다.
3. [관객 정보 입력 및 저장] : 관객들의 정보를 입력받아 저장한다.
4. [경주 진행] : 경주를 진행시켜 말과 선수의 경기 현환을 매 회 출력하고 순위를 만들어 낸다.
5. [예외 케이스 생성] : 아픈 말을 조건에 맞게 랜덤으로 설정한다.

6. [정산 후 출력] : 환불을 받아야할 경우 환불 처리를 해주고, 최종 배당률을 계산해 사용자들에게 정산을 해준다.

## 예외처리

### 1. 이름 입력

[] 선수와 말의 이름은 , 를 기준으로 구분되어야 하며 , 이외에 다른 문자가 있으면 안된다.

- 선수@말 이름 : minuk@chichi
  [] 사용자, 선수, 말, 이름 사이에 공백은 없어야 한다.
- 선수와 말 : min uk,chi chi
- 사용자 : yeon jun

### 2. 관객 정보

[] 관객의 요금은 오직 숫자여야한다.

- 백만원
  [] 배팅승식 입력은 정확한 표기여야 한다.
- " 복승식 ", "@복 승"

### 3. 금액

[] 입장료와 베팅금액은 기준 값을 만족해야하고 문자, 공백이 있으면 안 된다.

- 입장료 : "2 000","300"
- 배팅금액 : "10 000",10,000","1@@@@
